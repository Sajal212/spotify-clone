# Spotify Clone 🎵

A Spotify-inspired music player web application developed as part of my Frontend Development coursework.

## Tech Stack
- HTML5
- CSS3
- JavaScript
- React.js (Planned)

## About the Project
This project aims to recreate a Spotify-inspired music player interface while implementing interactive frontend functionalities.

The application will be progressively enhanced with modern web technologies, including React.js.

## Future Enhancements
- Migrate existing UI components to React.js.
- Implement reusable React components.
- Improve music playback functionality.
- Add dynamic playlists and search functionality.
- Enhance responsiveness and user experience.

## Getting Started
1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the current HTML version using Live Server.

Academic Project – Frontend Development
